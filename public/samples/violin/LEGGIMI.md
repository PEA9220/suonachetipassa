# Campioni di violino

Mettere qui un set di campioni con licenza libera (scelto da Dario) e un `manifest.json`
che associa le note ai file, per esempio:

```json
{ "G3": "G3.mp3", "C4": "C4.mp3", "E4": "E4.mp3", "A4": "A4.mp3", "C5": "C5.mp3", "E5": "E5.mp3", "A5": "A5.mp3", "C6": "C6.mp3", "E6": "E6.mp3" }
```

Senza `manifest.json` l'app usa un sintetizzatore FM di ripiego.
